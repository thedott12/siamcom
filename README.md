# Siam Computer & Language School

Статическая главная страница школы на тайском и английском. Тайская версия находится в `index.html`, английская — в `en/index.html`. Стили, сценарии, фотографии и шрифты входят в репозиторий.

## Локальный просмотр

Из корня репозитория запустите `python -m http.server 8000 --bind 127.0.0.1`. Откройте [главную](http://127.0.0.1:8000/) или [английскую версию](http://127.0.0.1:8000/en/). Страницы можно размещать в подкаталоге статического хостинга.

Поиск, пункты About, Contact и Literacy, социальные ссылки и интерактивная карта используют исходные внешние адреса. Переключатель фотографий и карусель курсов работают локально. Памятное объявление можно закрыть и повторно открыть через «Click it!».
